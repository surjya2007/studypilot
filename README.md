
# StudyPilot — Student Productivity Hub

StudyPilot is a lightweight student productivity web application built using HTML, CSS, and JavaScript.

## Features

- Dashboard overview
- Task manager with priorities and deadlines
- Study planner
- Pomodoro focus timer
- Personal notes
- Expense tracker
- Dark and light themes
- Local storage persistence

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or backend server required.
